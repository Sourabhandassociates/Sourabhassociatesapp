Global toast notifications

This frontend now uses react-hot-toast for API mutation feedback.

After extracting this frontend, run:
  npm install
  npm run build
  npm run dev

The first npm install updates package-lock.json and installs react-hot-toast.

Create / Edit / Delete success and failure notifications are attached to the shared Axios API client, so they apply to mutations made through the app's shared api instance. Read-only GET requests do not trigger notifications. Authentication and announcement read-tracking actions are excluded.

Important: this upload contains only the frontend. The current frontend has an announcement detail/read screen, but no announcement creation page or create form. Implementing announcement creation end-to-end requires the backend ZIP/API routes so the UI can call the actual supported endpoint safely. No announcement API endpoint has been invented in this patch.
