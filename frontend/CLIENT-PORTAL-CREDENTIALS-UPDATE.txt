CLIENT PORTAL CREDENTIALS UPDATE

Changes:
- New Client form now accepts an optional custom Client Portal Username and Password.
- Leaving either blank retains existing behavior: auto-generated Client ID and/or temporary password.
- Client Details includes a separate form to change the portal username and/or password.
- Password inputs are masked and are not prefilled.

Deployment:
1. Back up the current frontend.
2. Extract this archive into the frontend project directory.
3. Run: npm ci
4. Run: npm run build
5. Upload the generated dist/ contents to the existing frontend web root.

Backend update is also required. Deploy the matching backend ZIP so the credentials endpoint is available.
