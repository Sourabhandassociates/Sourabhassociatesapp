Client login update
====================

The Client Login form now accepts either a Client ID or the registered client
name, together with the existing password.

No database migration is required.

Build and deploy:
1. Run `npm ci`.
2. Run `npm run build`.
3. Upload the contents of the generated `dist` folder to the frontend web root
   (for example, public_html), replacing the old frontend assets after backup.

This source package intentionally excludes node_modules and dist. The existing
uploaded dist was built before this change and must not be deployed as the new UI.
