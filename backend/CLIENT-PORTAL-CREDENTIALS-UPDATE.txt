CLIENT PORTAL CREDENTIALS UPDATE

Changes:
- Create Client accepts an optional custom Client Portal username (Client ID) and optional password.
- If username is blank, the existing sequential Client ID is generated.
- If password is blank, the backend generates a secure temporary password and returns it once in the create response.
- Client Details has a separate credential update form for changing the portal username and/or password.
- Passwords are stored as hashes; plaintext passwords are never returned by client detail/list APIs.
- Changing either credential revokes active client portal sessions.
- Credential updates are audited and require CLIENTS.EDIT permission.

Deployment:
1. Back up the current backend and preserve the production .env file.
2. Extract this archive into the existing backend project directory (the archive contains a backend/ folder).
3. Run: npm ci
4. Run: npm run build
5. Restart the Hostinger Node.js application.

No database schema migration is required for this update.
